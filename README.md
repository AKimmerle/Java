## Java Projects

These are all personally projects I made in the beginning for 2026 (Around January 2026 to April 2026). Each project has a unique functionality and purpose that are served to be purely for fun as well as prepare me for my AP Computer Science A exam.

## Features

 - ChestManager: A program inspired by Minecraft that tracks what is put into a chest. 
 - EnchantmentTracker: A program inspired by Minecraft that tracks the enchantments of tools
 - FFXIVJobWiki: A Final Fantasy 14 wiki about the jobs based on the Dawntrail Expansion
 - FireteamStats: A program inspired by Destiny 2 that uses a team's stats to calculate the best KD, average KD and best killer
 - GameScoreboard: Revolves around taking people's scores during multiple rounds and seeing who's the top scorer and who's improved every round
 - Loadout: A program inspired by Destiny 2 that uses a guardian's weapons and power level
 - NumberGuesser: A game where you guess a number
 - OverwatchMiniWiki: An Overwatch wiki about the heros and their attributes 
 - TicTacToe: A fun TicTacToe game you can play with your friend
 - wordsStats: A program that shows that vowels of a word, the constants of a word, the word itself, and the length of the word
